# Data

`behavioural_demo.csv` contains synthetic demonstration data created for the INSIDERGUARD AI learning and research prototype.

It is not the CERT Insider Threat Dataset. Any model results produced using this file are for demonstration purposes only and must not be interpreted as real-world or research performance.

For the future research version, the CERT Insider Threat Dataset should be obtained from its authorised source. Raw CERT data should remain outside the public GitHub repository unless redistribution is explicitly permitted by the dataset licence or provider.

The public repository is intended to contain code, documentation, reproducible workflows, and appropriately shareable demonstration data only.
