# Research Roadmap

INSIDERGUARD AI is an experimental research and learning prototype exploring AI-assisted insider-threat detection using behavioural activity data.

The current version focuses on building a transparent and reproducible baseline workflow before introducing more advanced research methods.

## Current implementation

- Synthetic behavioural demonstration dataset
- Data preprocessing and feature handling
- Random Forest baseline classifier
- PyTorch neural-network baseline
- Side-by-side model comparison
- Precision, recall and F1-score evaluation
- Confusion-matrix analysis
- Model persistence and prediction
- Interactive Streamlit dashboard
- Automated pipeline tests
- Reproducible Python project structure

## Short-term development

Planned improvements include:

- Stronger data validation and preprocessing
- More detailed model evaluation
- Improved behavioural feature engineering
- Better documentation of experiments
- Additional visualisation of model behaviour
- Improved reproducibility and testing

## Future research directions

Future research may investigate:

1. Explainable AI using methods such as SHAP or LIME
2. Privacy-preserving machine learning
3. Federated learning across distributed environments
4. Non-IID behavioural data
5. Class imbalance and rare-event detection
6. Appropriately obtained CERT insider-threat datasets
7. Analyst-oriented explanations and decision support
8. Integration with SIEM and security-monitoring environments

## Research principles

Future development will prioritise:

- Reproducibility
- Transparent evaluation
- Responsible use of behavioural data
- Privacy and ethical considerations
- Clear distinction between demonstration results and validated research findings
- Appropriate documentation of datasets and experimental limitations

## Current limitations

The present system is a research and learning prototype using synthetic data.

It is not a production insider-threat detection system and should not be used to assess real employees or make operational security, employment or disciplinary decisions.

Results generated by the current demonstration dataset must not be presented as real-world detection performance.

## Long-term objective

The longer-term objective is to investigate how artificial intelligence, behavioural security analytics and privacy-aware learning methods can support more transparent and effective insider-threat detection while addressing the technical, organisational and ethical challenges associated with monitoring human activity.
